# Greenhats 个人作品集网页

这是可在本地运行的静态网页文件包，包含环绕式首页和七个详情页。英文版是 `index.html`，中文版是 `zh.html`，两者是独立网页。线上版本已部署于 https://greenhats.dev/。

从首页正上方开始，顺时针阅读顺序为：**Experience → Skills → Gallery → Achievements → Travel → Internship → Contact**。详情页的编号、左下角圆环和滚轮切换均采用这一顺序。

首页在首次绘制时直接呈现完整构图，姓名快速逐字显现，卫星按钮随后各自缓慢上下浮动约 3 px，并带着图标在约 ±2° 内轻摆；悬停、聚焦或选中时停摆。桌面端首次进入时，Skills 卫星会短暂亮起并显示名称，提示按钮可以探索；访客开始操作后提示立即退出，在同一标签页内不重复播放。按钮和图标采用独立的合成层，减轻 SVG 线条在运动时的闪烁。系统开启“减少动态效果”时，持续动画会关闭。

左上角的 **Greenhats.** 字标与小轨道符号呼应首页主星球和卫星。右上角的 **EN / 中** 链接在两个独立网页间切换；切换时仅让内容区短暂淡化，页眉与构图不位移或缩放，并保留当前章节及其阅读位置。旁边的外观按钮提供“跟随系统 / 浅色 / 深色”三种模式；默认跟随系统，手动选择会在浏览器中保留。切换语言时也会沿用当前外观模式。

详情页共用字体、配色和左下角圆环，各自选用适合内容的版式：Skills 在宽屏呈现三列能力与使用场景，下方有一幅技术栈标识拼贴；Gallery 交错展示两个项目与关键事实，Experience 用时间线，Achievements 突出获奖结果，Travel 是明确的待补状态，Internship 简明表达 AI Agent / AI 全栈开发的求职方向，Contact 让邮箱成为主要入口。窄屏自动收为单列。手机端只在左下角保留小范围的环形入口，正文可以滚动到屏幕底部。页面没有底栏，章节切换控件位于上方。左下角圆环会随滚轮逐步跟随，需要明确的连续滚动才切换章节；切换后有固定的短暂缓冲，以减少误触。鼠标停在页眉等页面区域时也能使用滚轮，无须先点击。返回首页的交互保持可用。

## 查看

可直接打开英文页 `index.html` 或中文页 `zh.html`。推荐在此文件夹运行本地服务器，以确保跨页面偏好设置正常保留：

```bash
python3 -m http.server 8766
```

然后打开 `http://127.0.0.1:8766/`。

## 内容与来源

- Skills、Gallery、Experience：基于 [Green-hats 的 GitHub](https://github.com/Green-hats) 与用户提供的简历。
- Experience 的教育信息按用户指定的语言版本显示：英文为 Federation University Australia，中文为河北科技大学。
- Internship：仅表达希望寻找 AI Agent / AI 全栈开发方向的机会，并提供联系入口。
- Contact：简历中的邮箱和 GitHub；没有在网页上公开手机号。
- Achievements：按简历列出蓝桥杯与 MCM/ICM 奖项。
- Travel：没有提供真实记录，因此保留清楚的待补状态。
- Gallery 使用项目仓库中的真实界面截图：NutriGo 的 AI 对话界面与 AniGo 的订阅首页。截图已随网站文件打包，可离线显示；项目链接通向对应仓库。
- Skills 技术栈拼贴展示 Go、Python、React、TypeScript、FastAPI、Docker、SQLite 和 C++。除用户明确补充的 C++ 外，技术来自 [NutriGo](https://github.com/Green-hats/NutriGo) 和 [AniGo](https://github.com/Green-hats/AniGo) 的项目说明；标识来自 [Simple Icons](https://github.com/simple-icons/simple-icons)。

## 文件

- `index.html`：英文页面
- `zh.html`：中文页面
- `styles.css`：布局、配色和响应式样式
- `site.js`：环形导航、页面切换和滚轮交互
- `assets/images/character-320.webp`、`assets/images/character-640.webp`：根据屏幕密度加载的角色图
- `assets/images/nutrigo-chat.jpg`、`assets/images/anigo-home-1200.webp`：两张真实项目界面截图
- `assets/favicon.svg`：网站图标
- `assets/tech/`：技术栈 SVG 标识与 Simple Icons 许可文件
- `assets/fonts/`：本地 Poppins、Inter 与 Orbit WenKai 字体及其开源许可

标题的拉丁文字使用 Poppins，正文的拉丁文字使用 Inter；中文章节大标题使用设备上的宋体风格字体，中文次级标题、正文和导航使用 Orbit WenKai。Orbit WenKai 是基于[霞鹜文楷](https://github.com/lxgw/LxgwWenKai)制作并重命名的当前文案字体子集，许可见 `assets/fonts/OFL-WenKai.txt`。三种字体均随网站打包，可离线显示。新增未收录的汉字会退回设备上的宋体风格字体，需要时可重新生成子集。

## 图片加载

首页角色图已从 1.14 MB 的原始 PNG 转为约 16 KB / 37 KB 的透明 WebP；浏览器按屏幕密度选择版本。AniGo 截图使用约 21 KB 的 WebP。线上 `/assets/` 资源由服务器设置 7 天缓存。当前域名仍直连服务器；真正的边缘 CDN 需要配置域名 DNS 与 CDN 账户。

原始角色图和未压缩的 AniGo 截图保存在源码仓库的 `originals/` 文件夹中，不包含在此交付包内。
